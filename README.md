# Swing Lab 打擊揮棒動作實驗室

在瀏覽器中分析棒壘球打擊揮棒動作的單頁網站。上傳打擊影片後，以 MediaPipe Pose 逐幀辨識 33 點骨架，Three.js 呈現 3D 骨架，並與理想打擊模板對照。

## 功能

- 3D 骨架：橘色為實際動作、青色為理想模板，依打者體型自動縮放與對齊，可拖曳旋轉、切換視角
- 播放：同步播放、暫停、逐格、0.1× 慢放、單次循環、一鍵跳到擊球點
- 自動偵測：以手部速度峰值偵測每次揮棒與 IMPACT 擊球點
- 數據：打擊仰角、上半身與髖部旋轉、肩髖分離、揮棒速度（估計）、重心轉移、頭部位移、髖部領先肩膀時間
- 統計：揮棒疊圖、多次揮棒平均（可排除個別揮棒）、每種瑕疵的出現次數
- YouTube 參考影片：並排觀看對照（不做辨識）
- 內建示範資料（6 次揮棒、821 影格、30 fps），不上傳影片也能操作

## 使用方式

直接用 Chrome 或 Edge 開啟 `index.html`，或透過 GitHub Pages 開啟。第一次分析影片時會從網路下載 MediaPipe 模型（約 9 MB），需要連網。影片只在本機瀏覽器處理，不會上傳到任何伺服器。

## 拍攝建議

- 使用 120 fps 以上的慢動作拍攝；揮棒約 0.15 秒，30 fps 只拍得到 4 到 5 格
- 固定機位，讓打者全身入鏡，鏡頭方向垂直於投手到打者的連線
- 避免逆光與畫面中出現其他人

## 技術

- [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) Pose Landmarker（full 模型）
- [Three.js](https://threejs.org/) r128
- 單一 HTML 檔，無建置步驟、無後端

## 限制

- 不追蹤球棒：打擊仰角由手部軌跡估算，棒速由手速乘上固定比例粗估，適合同一人前後比較
- 單鏡頭 3D 推估的深度方向誤差較大
- 瑕疵門檻以內建理想模板為基準，並非針對個人的教練判斷
